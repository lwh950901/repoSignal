## Context

现有月报模型把主要角色、分类推荐、趋势信号和行动建议固化为结构化字段。该结构会诱导编辑为三个角色补齐内容，却不能证明项目适合真实业务，也不能说明多个仓库能否连接。当前七月月报的候选数与生成器不一致，进一步说明内容事实与构建校验之间缺少可审计边界。

本设计只重构月报研究和展示。周期导航、报告搜索、静态路由和 Astro 构建已经工作，不应借机重写。

## Goals / Non-Goals

**Goals:**

- 让 Top 5 的排名事实、判断和反对理由可追溯。
- 只发布有真实需求证据、竞品调查和仓库可行性结论的业务方案。
- 明确区分“已运行”“文档确认”和“推断”。
- 将完整研究证据与公开页面分离，同时保持 Git 版本化。
- 用七月真实研究验证新合同，再调整解析器和页面。

**Non-Goals:**

- 不自动从候选池生成商业结论。
- 不建立数据库、后台管理系统或构建期外部 API。
- 不承诺运行全部候选仓库或完成生产级组合。
- 不公开原始命令日志、凭据或内部研究目录。
- 不修改日报、周报数据格式和首页默认周期。

## Decisions

### Top 5 与业务方案使用独立判断

Top 5 对单仓库进行月度评分；业务研究判断需求、市场与组合可行性。业务方案至少由一个本月核心仓库触发，但可以加入历史或外部辅助仓库。任何一方都不能影响另一方的排名或入选。

### 公开 Markdown 保存冻结结论，研究 Markdown 保存证据

`monthly/YYYY-MM.md` 继续参与 Astro 构建。`monthly-research/YYYY-MM/` 保存评分表、竞品调查和验证摘要，不被 `import.meta.glob` 加载。发布页面直接链接官方外部来源，不公开内部研究目录。

### 解析器只结构化发布所需的稳定字段

Top 5 的事实、评分和来源全部结构化，以便严格校验和统一展示。业务方案的摘要、组合仓库与枚举字段结构化；真实问题、竞品、产品定义、数据流、MVP 和证据边界保留为固定子章节 Markdown 并渲染为 HTML。这样避免为研究文章的每一段建立脆弱的字段模型。

### 研究验证使用等级而不是二元结论

仓库验证采用 L0–L4，组合结论采用“已验证可行、文档层面可行、部分可行、暂不可行”。页面必须显示验证等级；L3 之前不得声称已经连接成功。

### 业务数量允许为零

公开月报必须有恰好五个 Top 5，但业务方案为 0–3 个。没有方案达到需求和技术门槛时展示明确空状态，不生成占位机会。

## Data Shape

`MonthlyReport` 保留月份、主题、截止日期、候选数量和结论，新增深度候选数量、运行仓库数量、Top 5 评分项目、业务方案和研究说明。

Top 5 项目包含仓库、当月变化、Stars、Forks、release、最近有效活动、许可证、核实日期、验证等级、六项评分、核心能力、工程成熟度、限制、反对理由、最终判断和来源链接。

业务方案包含形态、目标用户、需求状态、竞品数量、组合仓库、最高验证等级、可行性结论、商业判断、核实日期，以及固定正文子章节。

## Risks / Trade-offs

- [研究成本过高] → 第一版只深查约 15 个 Top 5 候选和最多 3 个业务假设，正式发布最多 3 个方案。
- [评分制造虚假精确感] → 展示分项证据并说明是编辑评分；首期试评分后只校准一次。
- [项目无法运行] → 明确记录阻塞原因和等级，不把文档推断写成运行成功。
- [外部事实后来变化] → 保存核实日期和来源；发布月报保持冻结，后续变化进入新一期。
- [Markdown 解析复杂] → 只结构化稳定枚举和摘要字段，长篇分析按固定子章节渲染。
- [研究文件意外公开] → 研究目录不加入页面 glob 和搜索；测试断言构建产物不包含内部路径。

## Migration Plan

1. 先建立研究文件模板和校验合同，不改公开页面。
2. 对七月候选完成 Top 5 评分、需求调查和仓库验证，形成冻结研究证据。
3. 用研究结果写新版七月公开 Markdown。
4. 以新版真实内容驱动解析器与组件的 TDD 重构。
5. 更新搜索摘要、README 与 OpenSpec tasks，运行完整验证和桌面/移动端检查。
6. 如需回滚，恢复旧七月 Markdown、`monthly.ts` 和 `MonthlyReportView.astro`；周期导航与其他报告不受影响。

## Open Questions

Top 5 权重、两类需求证据门槛、L2/L3 成本和每月可持续研究数量只能通过首期真实研究校准。第一版必须在研究文件中记录调整，不把这些值描述为经过长期验证的客观标准。
