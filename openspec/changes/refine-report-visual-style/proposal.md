## Why

RepoSignal 的现有灰绿配色与档案式布局已经形成统一身份，但辅助字号偏小、项目内部横线密集、重点色使用分散，使读者难以快速区分项目用途、推荐理由和风险。本次优化面向浏览开源项目的开发者，提高跨报告页面的扫读效率和长文阅读舒适度，同时延续现有视觉身份。

## What Changes

- 建立清晰的字号与字体分工：导航、标签和字段名以 12–13px 为目标，正文以 15–16px 为目标；中文标签使用正文黑体，等宽字体集中用于仓库名、日期和评分等技术信息。
- 调整内容层级与留白：保留项目之间及章节之间的分隔线，减少项目字段之间的重复横线，用间距区分字段与项目；突出推荐理由，降低技术标签的视觉权重，并保持定位、简介与事实字段的现有顺序。
- 明确色彩职责：保留纸张色、苔绿色和标记黄色；黄色集中表达当前选择或明确的本期重点，普通分类标签改用克制的浅底或文字样式，去除标签旋转。重点标记必须来自已有数据或选择状态。
- 强化归档日期的当前项：使用整行浅色背景、短竖条和文字强调共同标明当前日期，补充清晰的悬停与键盘焦点状态，兼顾归档栏收起状态和移动端日期选择器。
- 改善阅读宽度：长段落以约 42–46em 为目标控制行长，表格与评分区域可使用更宽的内容区；在窄屏和归档栏收起后仍保持合理字号、间距与内容边界。
- 引入与 RepoSignal 名称呼应的简短信号刻度：在已有数字评分旁提供映射同一分数的分段刻度，保留数字与满分语境；无评分项目继续显示“周选”，不显示评分刻度，也不推导新评分或等级。
- 在日报、周报、月报、每日可行性方案、开源雷达周刊及共享搜索界面中保持一致的基础视觉规则，保留既有原生展开控件、键盘操作、减少动态效果偏好和无 JavaScript 阅读能力。

## Capabilities

### New Capabilities

无。本次属于既有报告界面的视觉优化。

### Modified Capabilities

- `report-interface-refinement`: 扩展已有界面精修要求，覆盖可读字号与字体分工、内容密度与阅读宽度、颜色使用语义、归档选中状态，以及与真实数字评分一致且可访问的辅助刻度；继续保留既有档案式结构与渐进披露行为。

## Impact

- 主要涉及 `src/styles/global.css` 中的字号、字体角色、间距、分隔线、标签、选中态、正文宽度与响应式样式。
- 涉及 `src/components/ProjectEntry.astro` 的评分辅助刻度，以及 `DateRail.astro`、`ArchiveTimeline.astro` 等归档组件的当前项表现；其他报告与搜索组件按共享样式的影响进行必要适配。
- 需要核对 `src/components/layout-contract.test.ts` 的现有界面契约，并对评分与无评分状态、桌面和移动端、长仓库名和长段落、归档展开与收起、键盘焦点开展有针对性的验证与浏览器检查。
- 报告内容、评分来源、解析器、路由、周期导航顺序与日期解析逻辑保持现有契约；不新增运行时依赖、数据字段或外部服务。
