## Why

RepoSignal 已有日报、周报和月报，但面向公众号式阅读的“开源雷达周刊”仍停留在内部传播草稿中，读者无法在站内浏览或按期回看。新增独立公开入口可以沉淀更易阅读的周刊文章，同时保持研究周报与传播稿各自清晰的内容边界。

## What Changes

- 新增公开的开源雷达周刊内容目录，按 ISO 周保存审核后的冻结 Markdown；内部 `distribution-drafts` 继续不参与构建。
- 新增开源雷达周刊归档入口与单期静态页面，首期发布 `2026-W31` 文章及固定封面。
- 在共享顶部导航中新增“开源雷达周刊”Tab，并在月报、周报、日报和雷达周刊之间提供一致的静态跳转。
- 雷达周刊页面左侧复用现有归档时间线，按周显示日期列表、当前项和最新一期状态；移动端提供期数选择器。
- 雷达周刊正文保留封面、分组标题、项目链接、风险与试用建议，并在禁用 JavaScript 时保持完整可读。
- 增加内容发现、周期导航、归档列表、页面渲染和生产构建的自动化测试。

## Capabilities

### New Capabilities

- `open-source-radar-weekly`: 定义审核后雷达周刊的内容发现、静态路由、顶部入口、左侧按周归档和正文可读性要求。

### Modified Capabilities

- 无。

## Impact

- 数据：新增 `data/github-project-digest/radar/*.md` 公开冻结文章，并复用 `public/covers/` 中的固定封面资源。
- 页面与组件：新增雷达周刊列表页、单期页和文章视图；扩展共享周期导航、归档时间线和移动端选择器。
- 类型与加载：扩展报告导航类型，并新增雷达文章的发现、排序和 Markdown 渲染逻辑。
- 测试与构建：更新周期映射和布局契约测试，增加雷达内容解析与路由覆盖；Astro 仍保持纯静态构建，不增加数据库或服务端运行时。
