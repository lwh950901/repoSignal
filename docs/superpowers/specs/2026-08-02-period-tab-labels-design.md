# 报告周期 Tab 命名优化

## 目标

让顶部导航直接表达四类内容的定位，避免“月 / 周 / 日”信息不足，同时保持现有路由、排序和交互不变。

## 最终文案

- `monthly`：月度洞察
- `weekly`：每周精选
- `daily`：每日发现
- `radar`：开源雷达周刊

“月度洞察”覆盖月报中的 Top 5、业务机会和研究判断；“每周精选”对应筛选后的项目清单；“每日发现”对应持续发现流程。

## 展示与行为

- 四个 Tab 在桌面端和移动端都显示完整名称。
- 当前类型继续使用现有 `aria-current` 与下划线状态。
- 链接目标、最新一期解析、页面标题和归档名称不随本次改动变化。
- 390px 移动视口不得出现横向溢出，触控高度继续保持至少 `2.75rem`。

## 验证

- 更新导航契约测试，精确断言四个标签。
- 运行相关测试与生产构建。
- 在 390px 视口确认四个标签完整可见且无横向滚动。
