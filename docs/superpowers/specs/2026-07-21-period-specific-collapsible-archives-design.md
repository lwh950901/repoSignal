# 周报与日报独立归档侧栏设计

## 目标

- 周报页面左侧只展示周报列表。
- 日报页面左侧只展示日报列表。
- 两种侧栏在桌面端均可收起为保留展开按钮的窄栏。
- 移动端继续使用只包含当前周期报告的下拉选择器。

## 方案

`/weekly/[week]/` 与 `/daily/[date]/` 已经是独立 Astro 页面，因此不复制正文组件。两个页面仍复用 `ReportView`，但只向它传入当前周期的报告数组和周期类型。

`DateRail` 改为接收单一 `reports` 与 `period`：周报生成周链接，日报生成日链接。它复用月报已有的渐进增强折叠状态和 CSS；无 JavaScript 时不显示折叠按钮，普通归档链接仍可导航。

## 行为

- 周报：标题为“周报归档”，数量只统计周报，下拉和桌面链接只包含 `/weekly/`。
- 日报：标题为“日报归档”，数量只统计日报，下拉和桌面链接只包含 `/daily/`。
- 桌面：点击按钮在完整侧栏与 `3.25rem` 窄栏之间切换，并同步 `aria-expanded`。
- `≤768px`：隐藏折叠按钮和桌面列表，显示当前周期下拉。

## 不做

- 不新增 `WeeklyReportView` 或 `DailyReportView`，除非两种正文未来出现实质不同。
- 不建立通用月/周/日归档框架。
- 不保存折叠状态，不引入依赖。

## 验证

一个聚焦测试锁定：周页不接收日报归档、日页不接收周报归档、折叠按钮可访问、移动端选择器仍可跳转。随后运行完整 Vitest、Astro check、生产构建和桌面/360px 页面检查。
