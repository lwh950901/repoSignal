# GitHub 每日发现自动化记忆归档

本目录保存 `GitHub 优质项目每日发现` 自动化的历史运行记忆，用于审计、故障回溯和确认用户过去的特殊决定。

普通每日运行不得默认读取 `archive/` 下的文件。只有当前记忆无法解释故障、权威状态文件发生冲突、需要确认历史用户决定，或用户明确要求回溯时，才按需读取相关归档。
