## 1. pydantic-ai

- 仓库：[pydantic/pydantic-ai](https://github.com/pydantic/pydantic-ai)
- 项目简介：Pydantic 团队维护的 Python GenAI/Agent 框架，面向需要类型安全、结构化输出、工具调用和可观测链路的生产应用。它以 Python 包、文档、示例、evals 和图执行组件交付。
- 入选理由：本周候选中生产可用性、维护节奏和文档完整度最均衡；类型安全、依赖注入、结构化输出、MCP、evals 和 OpenTelemetry/Logfire 能直接覆盖真实 Agent 工程需求。
- 质量与维护：实时仓库页显示约 18.6k Stars、2.4k Forks、356 Issues、132 PRs、2,446 commits、285 个 Releases，latest 为 v2.12.0 on 2026-07-17；README 提供完整示例、provider 覆盖、可观测、evals、durable execution 和 human-in-the-loop 能力说明，仓库含 docs、examples、tests、Security policy、Contributing。
- 主要技术栈：Python、Pydantic、Agent Framework、MCP、OpenTelemetry、Logfire、Evals。
- 实时指标：约 18.6k Stars / 2.4k Forks；MIT license；latest release v2.12.0 on 2026-07-17；仓库未见归档标记。
- 真实风险：Issue/PR 数较高，说明框架处于快速演进期；Logfire、模型供应商和高级能力会带来成本、运维和版本锁定问题。
- 上手建议：先用 README 的最小 `Agent` 示例跑通结构化输出，再接一个真实内部工具和一组 evals；生产前固定版本并验证目标 provider、审批流和 tracing。
- 本周精选价值：它是本周最适合作为 Python Agent 工程基线的项目，能把原型脚本推进到可测试、可观测、可维护的应用结构。

- 主要技术栈：Python、TypeScript、LangChain、LangGraph、Node.js、Docker、Helm、Agent Skills。
- 实时指标：约 77.3k Stars / 10.5k Forks；MIT license；latest release DeerFlow 2.0.0 on 2026-06-25；仓库未见归档标记。

- 本周精选价值：它提供了本周最完整的 Agent 产品化样本，能帮助判断开源长任务 Agent 平台离真实工作流还有多远。

- 质量与维护：实时仓库页显示约 12.6k Stars、2.4k Forks、76 Releases，latest 为 1.18.0 and 1.18.0-beta28 on 2026-07-17；README 链接 plain Java、Quarkus、Spring Boot、Helidon、Micronaut 示例和文档，仓库页可见 Apache-2.0、Code of Conduct、Contributing、Security policy。
- 主要技术栈：Java、Maven/Gradle、Spring Boot、Quarkus、MCP、RAG、Vector Stores、LLM Providers。
- 实时指标：约 12.6k Stars / 2.4k Forks；Apache-2.0 license；latest release 1.18.0 and 1.18.0-beta28 on 2026-07-17；仓库未见归档标记。
- 真实风险：功能面很宽，open issues 数量高；企业落地需要锁定版本，并逐一验证目标模型、向量库、MCP 工具和 Spring/Quarkus 集成组合。

- 本周精选价值：它补足了本周偏 TypeScript/Python Agent 候选中的 JVM 生产路线，是 Java 团队最值得优先评估的项目。

## 4. CodeBurn

- 主要技术栈：TypeScript、Swift、JavaScript、CLI/TUI、macOS Menubar、Web Dashboard、OTLP。
- 实时指标：约 8.7k Stars / 685 Forks；MIT license；latest release CodeBurn Desktop 0.9.16 on 2026-07-17；仓库未见归档标记。
- 真实风险：依赖各 AI 编程工具的本地日志/session 格式，供应商变动会影响解析准确性；团队同步和遥测能力需要额外隐私审查。

## 10. CubeSandbox

- 仓库：[TencentCloud/CubeSandbox](https://github.com/TencentCloud/CubeSandbox)
- 项目简介：基于 RustVMM/KVM 的 AI Agent 代码执行沙箱，提供硬件隔离、快照、克隆、回滚和 E2B 兼容接口。
- 入选理由：它来自 2026-07-14 的额外发现，同周日报评分 89/100；与一般容器沙箱相比，硬件虚拟化和 E2B 兼容使其更适合高风险代码执行场景。
- 质量与维护：日报核验到单机与多节点部署、快照/克隆/回滚、vault、出口白名单和自动休眠；近期修复 Connect、PTY、ARM 快照和 PVM 等问题，最新快照版本为 `v0.5.1`。
- 主要技术栈：Rust、RustVMM、KVM、Go、Python/Node SDK、Terraform、eBPF。
- 实时指标：约 10k Stars / 983 Forks；Apache-2.0；`v0.5.1`（沿用 2026-07-14 日报快照）。
- 真实风险：依赖 Linux x86_64、KVM 或 PVM 能力，网络、模板和集群部署成本不低；版本仍早，隔离承诺需要结合自身威胁模型验证。
- 上手建议：在隔离测试集群用 E2B SDK 跑最小任务，依次验证快照恢复、网络出口和凭据隔离，再决定是否承载不可信代码。
- 本周精选价值：它补足了 Agent 框架之外最关键的执行安全层，让本周清单从“如何构建 Agent”延伸到“如何安全运行 Agent”。
