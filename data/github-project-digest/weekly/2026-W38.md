- 入选理由：日报将其列为学习型候选，提供论文、训练入口、环境案例、测试和轨迹指标导出；实时 README 进一步给出 10 个内置环境、StarPO 两阶段训练、RAGEN-2 的互信息诊断和可复现实验入口，学习对象具体且不可被生产化宣传替代。
- 质量与维护：仓库页显示约 593 次提交，含 cases、config、docs、tests、梯度分析、训练脚本和 veRL 子模块；约 28 个 Issue、1 个 PR，MIT。README 记录 RAGEN-2 于 2026-03-12 发布研究成果，但没有正式 GitHub Release，日报的 2026-08-23 研究入口更新和 2026-04-14 性能/JSONL 改动是最近可用活动证据。
- 主要技术栈：Python、PyTorch/LLM RL、StarPO、PPO/GRPO、Gym 环境、veRL、JSONL 指标。
- 实时指标：GitHub 仓库页约 2.8k Stars / 227 Forks，MIT，公开且未归档；无正式 Release，README 提供 RAGEN/RAGEN-2 论文和复现实验入口。
- 真实风险：需要 GPU、模型服务、环境依赖和严格版本固定，veRL 子模块与研究型训练流程复现成本高；README 文档部分已标注过时，StarPO、诊断指标和奖励设计不宜直接当作生产 Agent 框架照搬。
- 上手建议：先按 setup 脚本运行 Sokoban 小环境，记录 rollout、reward、entropy 和 mutual-information 指标，再阅读训练/诊断代码；不要在没有基准和资源预算时直接扩展到生产任务。
