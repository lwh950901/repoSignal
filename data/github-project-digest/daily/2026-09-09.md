## 主推荐

### 1. 爆发型：AlexsJones/llmfit — 90/100

- 仓库：[AlexsJones/llmfit](https://github.com/AlexsJones/llmfit)
- 一句话定位：根据本机硬件和模型文件参数判断哪些本地 LLM 能运行、应采用什么量化与后端。
- 类型与适合用途：爆发型；适合准备在个人电脑或工作站部署 GGUF、MLX 等本地模型的开发者。
- 核心亮点与场景：把内存、显存、模型大小、量化和推理后端放进同一选型过程，减少盲目下载和反复试错。
- 主要技术栈：Rust、GGUF、MLX、llama.cpp、本地硬件检测。
- 实时指标：2026-09-10 补录时 35,522 Stars / 2,258 Forks；MIT；公开、未归档。
- 近期有意义活动：2026-09-10 仍有推送；GitHub Trending 补录快照显示当日约新增 247 Stars。
- 质量证据：仓库提供 CLI 使用与模型适配说明，主题覆盖 GGUF、MLX、LocalAI 和 Unsloth；持续提交与问题区可用于核对硬件兼容边界。
- 风险：估算不能替代真实推理基准；上下文长度、KV cache、并发和驱动版本都可能让“能装下”不等于“足够快”。
- 推荐理由：当前 Stars 超过 5,000 且有明确日期的 Trending 加速证据，解决的是本地模型部署前最实际的容量判断问题。

- 仓库：[getmaxun/maxun](https://github.com/getmaxun/maxun)
- 一句话定位：通过录制浏览器操作或自然语言配置，把网站转成结构化数据、定时任务和 API。
- 类型与适合用途：实用型；适合市场研究、价格监控、目录采集和为 Agent 构建受控网页数据入口的团队。
- 核心亮点与场景：同时支持 Extract、Scrape、Crawl、Search、文档/OCR、SDK、CLI 与 MCP，可从无代码录制逐步过渡到程序化调度。
- 主要技术栈：TypeScript、Playwright、Node.js、PostgreSQL、Docker、MCP。
- 实时指标：2026-09-10 补录时 17,403 Stars / 1,505 Forks；AGPL-3.0；公开、未归档。
- 近期有意义活动：2026-09-09 仍有推送；Release Atom 显示 v0.0.46 于 2026-08-25 发布。
- 质量证据：README 提供 Docker Compose 与本地安装、升级、自托管、SDK/CLI 文档；能力和示例覆盖分页、登录、调度、截图、OCR 与结构化导出。
- 风险：网页条款、robots、登录凭据、代理来源和个人数据处理需要单独合规；AGPL 会影响闭源服务集成，自动恢复也不能保证页面改版后数据仍正确。
- 推荐理由：安装、文档、可运行示例、Release 和持续维护证据齐全，能直接验证一个端到端采集任务。
