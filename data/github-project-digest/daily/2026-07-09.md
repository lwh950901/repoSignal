- 仓库：[nexu-io/open-design](https://github.com/nexu-io/open-design)
- 一句话定位：面向编码代理的本地优先开源设计工作台，把 Codex、Claude Code、Cursor 等 CLI 变成可产出 HTML/PDF/PPTX/MP4 的设计引擎。

- 核心亮点与场景：桌面应用、MCP、插件、Skills、`DESIGN.md` 设计系统和导出流水线放在同一仓库；可用于把品牌规范转成可运行原型、生成 deck、制作动效视频或让编码代理按设计系统改造前端。
- 主要技术栈：TypeScript、HTML、CSS、JavaScript、Astro、Python。
- 实时指标：76,315 Stars / 8,710 Forks；Apache-2.0；仓库未归档；GitHub 页面显示约 76.3k Stars、8.7k Forks 和 Apache-2.0 license。

- 风险：项目增长异常快且 PR/Issue 数量较高，需实测桌面端稳定性、导出一致性和第三方模型成本；README 标注部分 bundled skills/templates 保留各自许可证，商用前需要核对子目录许可证。
- 推荐理由：社区爆发、发布密度、文档完整度和 Agent-native 设计场景高度匹配今天主题，且不是纯内容清单，能直接形成可试用工作流。
