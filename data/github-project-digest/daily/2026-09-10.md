- 主要技术栈：TypeScript、Bun、Elysia、Docker、Tailwind CSS、文件转换工具链。

- 近期有意义活动：2026-09-09 仍有推送；最新稳定 Release v0.18.0 发布于 2026-06-21。
- 质量证据：README 提供 Docker Compose、镜像标签、开发命令和截图；GHCR/Docker Hub 有稳定与 main 通道，Issue 区按 converter request 扩展格式。
