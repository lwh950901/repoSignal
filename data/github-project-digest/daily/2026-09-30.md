## 主推荐

### 1. 实用型：blakeblackshear/frigate — 83/100
- 仓库：[blakeblackshear/frigate](https://github.com/blakeblackshear/frigate)
- 一句话定位：面向 IP 摄像头与 Home Assistant 的本地实时目标检测 NVR。
- 类型与适合用途：实用型；适合搭建本地家庭/小型场所视频监控与事件检索。
- 核心亮点与场景：运动检测触发目标识别，集成 MQTT、RTSP 与低延迟 WebRTC/MSE；可将录像保留策略绑定检测对象。
- 主要技术栈：Python、OpenCV、TensorFlow，支持 GPU/AI 加速器；代码库还含 TypeScript 前端。
- 实时指标：36,177 Stars、3,643 Forks；MIT 许可证（当日 GitHub API 快照）。
- 近期有意义活动：主分支最近推送于 2026-09-30 01:43（Asia/Shanghai）；v0.18.0 于 2026-09-12 发布。
- 质量证据：README 指向完整文档并列出部署集成能力；仓库包含测试目录与 Docker Compose；近期有版本化 Release。
- 风险：实时检测建议使用 GPU/专用加速器；摄像头兼容性与硬件成本需先核实。Frigate 名称与商标不随 MIT 代码许可开放。
- 推荐理由：本地推理、自动化集成、活跃维护和版本发布都可从仓库直接验证，适合拿现有摄像头做一次端到端试用。

- 质量证据：有独立文档、路线图和多语言 README；近期版本持续修复平台接入与工具调用问题。

- 推荐理由：其平台适配与插件边界清晰，二次开发可从新增 IM Adapter 或实现一个领域插件切入；文档、多语言说明和连续 Release 提供了可检查的工程基础。
