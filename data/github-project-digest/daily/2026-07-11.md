### 1. 爆发型：microsoft/SkillOpt — 89/100

- 仓库：[microsoft/SkillOpt](https://github.com/microsoft/SkillOpt)
- 一句话定位：用轨迹驱动编辑、验证门和可部署 `best_skill.md` 训练可复用自然语言 Agent 技能的优化器。

- 核心亮点与场景：把技能文档当作可训练状态，支持 rollout、reflect、aggregate、select、update、evaluate；v0.2.0 引入 SkillOpt-Sleep，可在夜间从历史会话中挖掘任务、回放、合并并用 held-out gate 阻止退化。
- 主要技术栈：Python、HTML、Shell、PyPI、Gradio WebUI、Codex/Claude Code/Copilot/Devin/OpenClaw 插件壳。
- 实时指标：12,103 Stars / 1,121 Forks；MIT；非归档；GitHub Search API pushed_at 为 2026-07-02T14:11:34Z。
- 近期有意义活动：GitHub Release 页面显示 2026-07-02 发布 SkillOpt v0.2.0；Commit Atom 显示同日 release commit，2026-06-30 合入 secret redaction、Codex 失败显式暴露、validation gate 压力测试和 minimax backend 配置等实质维护。
- 质量证据：仓库页显示 213 commits、tests、docs、CHANGELOG、CONTRIBUTING、SECURITY 和 MIT license；README 提供安装、训练/eval、后端扩展、benchmark 和 WebUI 路径；近期提交包含安全脱敏、失败诊断和防 reward-hacking 测试。
- 风险：研究型工具仍依赖外部模型与 benchmark 设定，README 中的提升幅度需要在自己的任务集复测；v0.2.0 仍年轻，生产化采用前要验证会话数据采集和隐私边界。
- 推荐理由：它把“写提示词/技能”推进到可测试、可回放、可拒绝退化的优化流程，增长强、维护证据扎实，且直接贴合 Agent 工程化的下一步需求。
