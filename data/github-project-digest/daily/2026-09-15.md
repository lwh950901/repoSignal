## 主推荐

### 1. 爆发型：alibaba/open-code-review — 94/100

- 仓库：[alibaba/open-code-review](https://github.com/alibaba/open-code-review)
- 一句话定位：把确定性规则流水线与 LLM Agent 结合的多语言代码审查工具。
- 类型与适合用途：爆发型；适合需要在 CI 或代码评审链路中引入可审计 AI 审查的团队。
- 核心亮点与场景：规则先行、行级评论和 OpenAI/Anthropic 兼容接口，可用于安全规则与语义审查并行的 PR 门禁。
- 主要技术栈：多语言规则、LLM Agent、GitHub Actions。
- 实时指标：约 25.7k Stars / 1.9k Forks，Apache-2.0，未归档。
- 近期有意义活动：GitHub Trending 同轮记录当日新增 1,571 Stars；v1.12.1 于 2026-09-14 发布，仓库页显示 685 次提交。
- 质量证据：README 提供中英等多语言说明；含 CONTRIBUTING、治理文件、Apache-2.0 许可证与 Actions；发布页显示签名版本提交。
- 风险：这是 90 天内重复推荐，且 LLM 审查会引入模型成本、误报与代码外发边界，需要先在非阻塞模式校准规则。
- 推荐理由：近期热度与版本活动同时出现，且其“规则确定性 + Agent 语义判断”的边界非常适合拆入现有审查流程。

### 2. 实用型：questdb/questdb — 90/100

- 仓库：[questdb/questdb](https://github.com/questdb/questdb)
- 一句话定位：为实时分析、金融行情和遥测数据设计的高性能开源时序数据库。
- 类型与适合用途：实用型；适合需要快速启动本地/容器化时序存储，并以 SQL 服务实时指标或行情数据的团队。
- 核心亮点与场景：面向低延迟写入、时间序列 SQL 和高基数窗口查询；可作为交易、IoT 与可观测数据管线中的查询存储层。
- 主要技术栈：Java、SQL、Apache Arrow、Parquet。
- 实时指标：17,321 Stars / 1,646 Forks，Apache-2.0，未归档。
- 近期有意义活动：搜索快照显示 2026-09-14 仍有推送；10.0.1 于 2026-08-24 发布，改进 SQL、Live Views、存储、Web Console 与并发故障路径。
- 质量证据：发布说明明确列出扩展的 fuzz、故障注入和并发覆盖；连续发布线已进入 10.x；项目从 2014 年持续维护并提供可下载发行版与容器化启动路径。
- 风险：950 个开放 Issue 表明维护队列较大；高性能参数和数据模型需要按真实写入/查询负载压测，不能把发布基准直接当作自身结果。
- 推荐理由：它同时具备立即可运行的存储引擎形态、持续发布和面向故障路径的测试投入，适合作为实时数据产品的基础组件。

### 3. 潜力型：earthtojake/text-to-cad — 88/100

- 仓库：[earthtojake/text-to-cad](https://github.com/earthtojake/text-to-cad)
- 一句话定位：把自然语言需求转成 CAD、CAE 与 CAM 操作的 Agent Skills 工具集。
- 类型与适合用途：潜力型；适合构建面向工程设计、自动建模和制造流程的垂直 Agent 原型。
- 核心亮点与场景：将 CADGen 版本、模型与每项 skill 的依赖声明绑定，使自然语言到几何/仿真/制造的操作可以被拆分并二次编排。
- 主要技术栈：Python、Agent Skills、CAD/CAE/CAM、Git LFS。
- 实时指标：15,762 Stars / 1,628 Forks，MIT，未归档。
- 近期有意义活动：搜索快照显示 2026-09-14 仍有推送；v0.5.1 于 2026-09-08 发布，发布提交带 GitHub 已验证签名。
- 质量证据：README 给出模型与 fixture 的获取边界；仓库含 CONTRIBUTING、SECURITY、依赖开发文件与 1,070 次提交；发布页提供连续版本记录。
- 风险：仍处于 v0.x，依赖的 CAD 运行环境和大文件资产会提高复现成本；设计结果必须经过专业工程校核。
- 推荐理由：它把泛化 Agent 能力落到可验证的工程工具链，适合作为垂直行业工作流和工具调用协议的二次开发底座。
