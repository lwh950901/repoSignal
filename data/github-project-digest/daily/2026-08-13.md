- 主要技术栈：TypeScript、Electron/Vite、WebGL 终端、Git worktree、桌面/移动端集成。
- 实时指标：43,760 Stars / 3,052 Forks；MIT；公开、未归档、非 fork（同轮 GitHub Search API）。
- 近期有意义活动：GitHub Release v1.4.180 于 2026-08-11 发布；提交页显示 2026-08-12 仍在修复 WSL watcher、远程 Agent、renderer、agent hooks 和 orchestration。
- 质量证据：仓库页约 8,499 次提交并有 docs、examples、src、native、tests 结构；Release 提供多平台签名构建和 22 个资产；README 明确给出 worktree、远程主机、批注和 CLI 使用路径。

- 主要技术栈：Python、Cactus 自研推理/量化引擎、CQ2-bit、GQA、LoRA、JSONL、Hugging Face、grammar-constrained decoding。

- 近期有意义活动：Search API pushed_at 为 2026-08-12T19:35:38Z；仓库页约 247 次提交；Release 页面未见正式版本条目。
- 质量证据：README 明确给出 Simple Attention Network 的论文与 ablation、benchmark、tests、playground 和 LoRA→quantize→build 链路；具体可拆解价值在于“模型结构、约束解码、工具检索和执行门控”被放在同一个小系统里。
- 风险：实现新鲜度高但通用性有限，README benchmark 需独立复现；不宜照搬之处是把 2-bit 权重、置信度 calibration 和自研 engine 直接用于安全关键动作，必须保留人工升级与真实数据评测。
- 推荐理由：它是今天最清晰的源码学习样本之一：可以沿着模型结构、推理内存、schema 约束和微调导出逐层拆解，且 MIT 许可降低了实验门槛。

- 实时指标：3,491 Stars / 443 Forks；Apache-2.0；公开、未归档、非 fork（同轮 GitHub Search API）。
- 近期有意义活动：GitHub Release v0.5.4 于 2026-07-30 发布，包含生命周期稳定性、乐观锁、WarmPool 限制和 Python SDK/Router 改进；提交页显示 2026-08-11 仍有性能测试、扩展目录重构和 OWNERS 更新。
- 质量证据：仓库约 808 次提交，包含 API、controller、extensions、Helm、examples、tests、SECURITY.md 和 RELEASE.md；README 明确区分 orchestrator 与低层隔离 runtime；Release 明确记录 breaking change 与并发一致性修复。
- 风险：它只负责 Kubernetes 层编排，不等于低层隔离本身；CRD、RuntimeClass、集群权限和持久化配置均需平台级运维，v0.x breaking change 也要求锁定版本并做升级演练。
- 推荐理由：它把 Agent 运行时从“启动一个容器”提升为可声明、可恢复、可预热的 Kubernetes 资源，适合已有 K8s 平台的团队做最小集成验证，也没有触发 90 天重复推荐。
