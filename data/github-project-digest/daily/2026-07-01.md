- 核心亮点与场景：支持 36 种 tree-sitter 语法、增量更新、图查询、HTML/JSON/Markdown 输出，以及面向多种编码代理的 skill / hook 安装；可用于替代代理对整个仓库的反复 grep 和全量读取。

- 质量证据：
  1. 仓库包含 `tests/`、GitHub Actions、`ARCHITECTURE.md`、`SECURITY.md` 和长篇 changelog，不是单页 Demo。

- 核心亮点与场景：规范把机器可读 token 和人类可读 rationale 放在同一文件；官方 CLI 支持 `lint`、WCAG 对比度检查和设计版本 `diff`，可直接进入现有 npm/CI 流程。

- 质量证据：
  1. 规范定义 token 类型、引用、章节顺序、未知字段处理和组件状态，不只是提示词模板。
