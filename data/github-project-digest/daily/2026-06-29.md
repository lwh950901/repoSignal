## 1. 爆发型：DeusData/codebase-memory-mcp

**一句话定位：** 用 Tree-sitter 与混合 LSP 在本地把代码库索引为持久知识图谱，并通过 MCP 为编码 Agent 提供结构查询、调用链和影响分析。

- **类型与适合用途：** AI/Agent 基础设施、开发工具；适合大型仓库探索、跨服务调用追踪、改动影响分析，以及减少 Agent 逐文件读取的上下文消耗。
- **核心亮点与场景：** 单一静态二进制、无外部运行时；支持 158 种语言的语法解析，并为主流语言增加类型解析；提供 14 个 MCP 工具、跨仓库图谱和本地可视化。
- **主要技术栈：** C 88.4%、C++ 10.1%，Tree-sitter、SQLite/FTS5、LZ4、MCP；少量 Shell、TypeScript、Python。
- **实时指标：** **20,090 Stars / 1,450 Forks**；非归档、非 Fork；MIT。
- **近期有意义活动：** GitHub API 显示 2026-06-29 08:20（UTC+8）仍有推送；6 月 28 日合并内存轨迹诊断与泄漏 soak CI、MCP 协议兼容和多语言解析修复。最新 Release `v0.8.1`（2026-06-12），包含更完整的第三方许可证包、SBOM，并报告 5,604 项测试。
- **质量证据：** ① 仓库含 tests、test-infrastructure、CI、Security、Contributing 与维护者政策；② Release 产物提供校验和、Sigstore 签名与 SLSA 3 provenance；③ README 给出 64 个真实仓库的语言解析评测与可复现性能数据，但这些基准主要由项目方报告，仍需独立复测。
- **风险：** 当前约 174 个开放 Issue/PR，快速增长会放大维护压力；工具会读取代码并修改 Agent 配置，应先审计安装脚本并用 `--skip-config` 或手动安装；性能与“节省 99% tokens”等宣传性数字不能直接视为所有仓库的普遍结果。
- **推荐理由：** 今日 GitHub Trending 快照显示其单日增长超过 2,000 Stars，同时近期提交不是文档刷量，而是泄漏诊断、协议兼容、测试和多语言解析等实质改动。增长、维护与工程完整度同时成立。
- **评分拆分：** 社区 24/25、维护 24/25、质量 19/20、适合度 19/20、风险控制 8/10。

## 2. 实用型：simplex-chat/simplex-chat

**一句话定位：** 一个不以电话号码、用户名或固定用户标识寻址的端到端加密通信网络，覆盖 iOS、Android 和桌面端。

- **类型与适合用途：** 隐私通信、跨平台全栈应用；适合重视元数据保护的个人、小团队和希望研究安全消息协议的开发者。
- **核心亮点与场景：** 无全局用户身份的通信模型；支持移动端与桌面端；协议、客户端、机器人、网站和测试集中在同一成熟仓库，便于审计和学习。
- **主要技术栈：** Haskell 为核心，配套 Kotlin/Swift/Compose 等移动与桌面技术；仓库还包含 Node.js 包、Nix 与 Docker 构建配置。
- **实时指标：** **15,316 Stars / 881 Forks**；非归档、非 Fork；AGPL-3.0（品牌与图形资产另有条款）。
- **近期有意义活动：** GitHub API 显示 2026-06-29 10:53（UTC+8）仍有推送；最新正式 Release `v6.5.5`（2026-06-17），增加匿名 BBS 凭证支持者徽章、协议签名验证前向兼容及多端修复；6 月 21 日继续修复群组管理员降级后的链接使用问题。
- **质量证据：** ① 6,000+ 提交、259 个 Release，长期连续交付；② 仓库有 tests、CHANGELOG、PRIVACY、Security 和多平台构建；③ Release 使用已验证签名，并把协议与客户端修复关联到具体 PR。
- **风险：** AGPL-3.0 对二次分发与网络服务修改有强 copyleft 义务，品牌/视觉资产也不属于 AGPL；安全通信协议复杂，私有部署或二次开发前需要独立威胁建模和升级策略；约 1,151 个开放 Issue/PR 说明项目规模与支持面很大。
- **推荐理由：** 它不是“新奇 Demo”，而是有多年发布记录、多个真实客户端和持续安全修复的可用产品；今日 Trending 的增长只是加分项，成熟度和维护连续性才是其进入实用型位置的主要原因。
- **评分拆分：** 社区 23/25、维护 22/25、质量 19/20、适合度 17/20、风险控制 7/10。

## 3. 潜力型：altic-dev/FluidVoice

**一句话定位：** 面向 macOS 的本地优先离线听写工具，可用 Parakeet、Whisper、Apple Speech 等模型向任意应用输入文本。

- **类型与适合用途：** 桌面效率、端侧 AI；适合写作、会议笔记、无障碍输入和希望把语音数据留在本机的用户。
- **核心亮点与场景：** Homebrew 可安装；支持 Apple Silicon 与通过 Whisper 支持的 Intel Mac；本地模型覆盖约 40 种语言，AI 润色、云提供商、历史与分析均可选；支持跨应用热键和命令模式。
- **主要技术栈：** Swift、Swift Package Manager、Xcode/macOS 原生 API，本地语音模型与可选 LLM 接口。
- **实时指标：** **3,847 Stars / 243 Forks**；非归档、非 Fork；GPL-3.0。
- **近期有意义活动：** GitHub API 显示 2026-06-29 06:50（UTC+8）仍有推送；最新 Release `v1.6.1`（2026-06-28），改进自定义词典、多个主听写快捷键、损坏模型缓存检测、下载进度/取消、Ollama 流式请求与通用架构产物。
- **质量证据：** ① 748 次提交、35 个 Release，不是一次性 Demo；② 有集成测试目录、SwiftLint/SwiftFormat 和公开的 `xcodebuild test` CI 路径；③ README 明确模型大小、语言、硬件限制、权限和隐私边界。
- **风险：** 仅支持 macOS 15+，完整模型体验偏向 Apple Silicon；需要麦克风和辅助功能权限，属于高权限桌面工具；项目仍快速迭代，约 80 个开放 Issue/PR，稳定性和升级回归需要持续观察；GPL-3.0 会约束闭源二次分发。
- **推荐理由：** 它在较小社区规模下展示了高发布频率、真实集成测试和清晰的本地隐私边界。功能已可用，但生态、平台覆盖与长期维护仍处成长期，因此放在潜力型而非实用型。
- **评分拆分：** 社区 20/25、维护 24/25、质量 17/20、适合度 18/20、风险控制 7/10。
