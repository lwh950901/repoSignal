- 风险：不宜照搬到通用生产推理服务；它是 model-specific、arm64-only，要求 macOS 26/Metal 4/Xcode 26，模型安装约 14.3 GB，且 README 明确模型可能重复或出错。学习价值在于拆解内存/IO/kernel 取舍，不在于直接替代成熟推理后端。
