### 4. 学习型：microsoft/markitdown — 90/100

- 一句话定位：将 PDF、Office、图片、音频、HTML、CSV、JSON、XML、ZIP、YouTube 和 EPUB 等内容转换为 Markdown 的转换器框架。
- 类型与适合用途：学习型；适合拆解格式适配器、可选依赖、插件扩展、OCR 接入、测试边界和安全契约，不以直接生产部署为首要目标。
- 核心亮点与场景：转换器覆盖面广，支持 Python API、CLI、Docker、插件和 OCR；适合学习如何把多种输入格式统一到结构化文本管线，为 RAG/文档处理准备入口。
- 主要技术栈：Python >=3.10、Hatch、可选 extras、插件 API、Docker、OCR/多模态扩展。
- 实时指标：174,086 Stars；12,719 Forks；MIT；未归档；GitHub Search 本轮记录 pushed_at 为 2026-07-29；最新可见 Release 为 v0.1.7。
