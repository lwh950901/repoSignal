## 共同新增证据与边界

- 安全方向：GitHub branch protection 明确存在必需 review、status check 与部署成功门槛；AI-Infra-Guard 官方 README 说明其 Agent/Skill/MCP/infra 扫描能力和 Docker/CLI 前置。二者证明人工门禁和扫描面存在，不证明自动修复采购意愿。
- 本地工作台：OpenWorker、FreeLLMAPI、ADK 与 Cognee 均提供可安装/本地或自托管路径。它们证明替代方案和组件接口存在；“用户愿意为本地优先付费”仍没有独立访谈或交易证据。
- 私有知识方向：商业企业知识访问和开源 Cognee 分别证明权限感知知识工作与自托管检索的替代存在；没有将产品文档推导成客户数量、预算、收入或市场规模。
- 组合验证：`docker info` 返回 Docker socket permission denied；隔离 Python 环境安装 `code-review-graph` 首先 DNS 失败，升权重试后因 TLS certificate verify failed 退出。没有使用 `--trusted-host`、关闭 TLS、替换镜像、读取真实数据或写入工作区。三条链路均维持 L3 未确认。
